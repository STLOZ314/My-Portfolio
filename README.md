"# Robert Birge | Web Developer Portfolio

A responsive, single-page portfolio introducing my work, skills, and contact details. The featured case study covers my role on a team Issue Tracker project and links to its live application, API, and public source repository.

## Public checkpoint

The portfolio is publicly viewable without a login at [https://stloz314.github.io/My-Portfolio/](https://stloz314.github.io/My-Portfolio/). Use this link as the in-progress checkpoint.

## Contents

- `index.html` — page content and semantic structure
- `style.css` — responsive layout, typography, and visual styling
- `script.js` — mobile navigation, current year, and portrait fallback
- `headshot.jpg` — portfolio portrait

## Run locally

This is a static site with no build step or package dependencies. From this directory, start a local web server:

```sh
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploy

The site can be hosted on GitHub Pages or another static host. For GitHub Pages, push the site files to the repository, then choose **Settings → Pages** and publish from the `main` branch and `/ (root)` folder. After the first deployment, use the Pages URL shown in the repository settings as the public portfolio link.
